# COFFEE SHOPS TIA ROSA

Projeto desenvolvido para a Atividade Ativa da disciplina. O sistema foi feito em Python e permite administrar produtos
e estoque, cadastrar clientes, registrar pedidos, consultar vendas e acumular pontos de fidelidade a cada R$ 10,00 em
compras.

## Foram utilizados os seguintes conceitos:

- Listas
- Dicionários
- Funções
- Laços
- Condicionais
- Tratamento de erros

 ## Como executar:

- Ter Python Versão 3 instalado;
- Baixar o projeto;
- Executar o arquivo main.py
